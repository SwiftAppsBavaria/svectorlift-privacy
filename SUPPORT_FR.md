# sVectorLift — Assistance

sVectorLift est une application macOS pour les anciennes bibliothèques de cliparts. Elle reconstruit en véritable SVG les dessins de l'époque CorelDRAW — documents CorelDRAW (.cdr), Corel Binary Meta File (.cmx), Windows Metafile (.wmf) et Computer Graphics Metafile (.cgm) — et affiche les QuickDraw 3D Metafiles (.3dm, .3dmf) sous forme d'image. La collection se parcourt dans une fenêtre dotée d'une arborescence de dossiers ; un fichier isolé ou une sélection entière s'exporte en une seule étape. Les fichiers purement bitmap sont exportés en PNG. sVectorLift n'est pas un outil de mise en page.

## L'aide dans l'application

sVectorLift contient une aide complète. Vous l'ouvrez depuis le menu ou avec ⌘/ (Commande–Barre oblique).

Elle explique le choix des dossiers source et destination, la consultation et la sélection des cliparts, l'export, les raccourcis clavier et le changement de langue.

## Questions fréquentes

**Un point d'interrogation s'affiche à la place de l'aperçu.**
Le fichier n'a pas pu être lu : il est endommagé, ou son format est inconnu de sVectorLift.

**Mon fichier porte l'extension .cdr, mais les autres outils ne l'ouvrent pas.**
Beaucoup de fichiers portant l'extension .cdr sont en réalité des fichiers CMX. sVectorLift lit les deux.

**Comment changer la langue de l'application ?**
macOS permet de définir la langue application par application : Réglages Système → Général → Langue et région → section « Applications ». Ajoutez-y sVectorLift et choisissez la langue souhaitée.
