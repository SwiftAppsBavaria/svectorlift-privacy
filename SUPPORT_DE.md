# sVectorLift — Support

sVectorLift ist eine macOS-App für alte Clipart-Sammlungen. Sie baut Zeichnungen aus der CorelDRAW-Ära — CorelDRAW-Dokumente (.cdr), Corel Binary Meta File (.cmx), Windows Metafile (.wmf) und Computer Graphics Metafile (.cgm) — als echtes SVG neu auf und rendert QuickDraw-3D-Metafiles (.3dm, .3dmf) als Bild. Die Sammlung lässt sich in einem Fenster mit Ordnerbaum durchstöbern; einzelne Dateien oder eine ganze Auswahl werden in einem Schritt exportiert. Dateien, die nur ein Rasterbild enthalten, werden stattdessen als PNG exportiert. sVectorLift ist kein Layoutprogramm.

## Hilfe in der App

sVectorLift enthält eine vollständige Hilfe. Du öffnest sie über das Menü oder mit ⌘/ (Command-Schrägstrich).

Sie erklärt die Wahl von Quell- und Zielordner, das Ansehen und Auswählen der Cliparts, den Export, die Tastaturkürzel und die Sprachumstellung.

## Häufige Fragen

**Statt einer Vorschau erscheint ein Fragezeichen.**
Die Datei konnte nicht gelesen werden — sie ist entweder beschädigt oder liegt in einem Format vor, das sVectorLift nicht kennt.

**Meine Datei hat die Endung .cdr, andere Programme öffnen sie trotzdem nicht.**
Viele Dateien mit der Endung .cdr sind in Wahrheit CMX-Dateien. sVectorLift liest beides.

**Wie stelle ich die Sprache der App um?**
macOS erlaubt die Sprachwahl pro App: Systemeinstellungen → Allgemein → Sprache & Region → Abschnitt „Programme". Dort sVectorLift hinzufügen und die gewünschte Sprache wählen.
