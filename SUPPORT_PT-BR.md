# sVectorLift — Suporte

O sVectorLift é um app para macOS feito para coleções antigas de clipart. Ele reconstrói como SVG de verdade os desenhos da era CorelDRAW — documentos do CorelDRAW (.cdr), Corel Binary Meta File (.cmx), Windows Metafile (.wmf) e Computer Graphics Metafile (.cgm) — e renderiza como imagem os QuickDraw 3D Metafiles (.3dm, .3dmf). A coleção pode ser explorada em uma janela com árvore de pastas; arquivos individuais ou uma seleção inteira são exportados de uma só vez. Arquivos que contêm apenas uma imagem raster são exportados como PNG. O sVectorLift não é um programa de diagramação.

## Ajuda no app

O sVectorLift inclui uma ajuda completa. Você pode abri-la pelo menu ou com ⌘/ (Command + barra).

Ela explica como escolher as pastas de origem e de destino, como visualizar e selecionar os cliparts, como exportar, quais são os atalhos de teclado e como mudar o idioma do app.

## Perguntas frequentes

**Aparece um ponto de interrogação no lugar da pré-visualização.**
Não foi possível ler o arquivo — ele está danificado ou em um formato que o sVectorLift não conhece.

**Meu arquivo tem a extensão .cdr, mas outros programas não conseguem abri-lo.**
Muitos arquivos com a extensão .cdr são, na verdade, arquivos CMX. O sVectorLift lê os dois.

**Como mudo o idioma do app?**
O macOS permite escolher o idioma de cada app: Ajustes do Sistema → Geral → Idioma e Região → seção “Aplicativos”. Adicione o sVectorLift ali e escolha o idioma desejado.
