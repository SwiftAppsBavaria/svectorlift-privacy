# Privacy Policy

**sVectorLift**
Last updated: July 14th, 2026

## Summary

sVectorLift does not collect, store, or transmit any personal data. All data remains exclusively on your device.

## Data Collection

sVectorLift collects **no** personal data. The app:

- Does not collect usage data or statistics
- Does not use any analytics or tracking services
- Does not establish network connections
- Does not send data to servers or third parties
- Does not contain advertising

## Local Data Storage

sVectorLift stores the following data exclusively on your Mac:

- **Folder bookmarks:** The source and destination folders you select are stored as security-scoped bookmarks so the app can retain access after a restart.
- **User preferences:** Simple settings such as the thumbnail size and the last opened folder are stored in local UserDefaults.
- **Thumbnail cache:** Rendered clipart previews are held in memory only and are not written to persistent storage.

This data never leaves your device and can be completely removed at any time by uninstalling the app.

## File Access

sVectorLift only accesses folders and files that you actively select (via the file dialog). It reads the clipart files you point it to and writes exported SVG/PNG files only to the destination folder you choose. The app operates within the macOS sandbox and has no access to other areas of your system.

## Third-Party Services

sVectorLift does not use any third-party services, SDKs, or frameworks that collect data.

## Children

Since sVectorLift does not collect any data, there are no specific risks for children.

## Changes

Changes to this privacy policy will be published in this file. Since no data is collected, significant changes are not expected.
