# Privacy Policy

**sVectorLift**
Last updated: October 30th, 2026

## Summary

sVectorLift does not collect, store, or transmit any personal data. All data remains exclusively on your device.

## Data Collection

sVectorLift collects **no** personal data. The app:

- Does not collect usage data or statistics
- Does not use any analytics or tracking services
- Does not establish network connections
- Does not send data to servers or third parties
- Does not contain advertising

## Local Data Storage

sVectorLift stores the following data exclusively on your Mac:

- **Folder bookmarks:** The source and destination folders you select are stored as security-scoped bookmarks so the app can retain access after a restart.
- **User preferences:** Simple settings such as the thumbnail size and the last opened folder are stored in local UserDefaults.
- **Thumbnail cache:** Rendered clipart previews are held in memory only and are not written to persistent storage.

This data never leaves your device and can be completely removed at any time by uninstalling the app.

## File Access

sVectorLift only accesses folders and files that you actively select (via the file dialog). It reads the clipart files you point it to and writes exported SVG, PNG or JPG files only to the destination folder you choose. At your request, it renames files in these folders, moves or copies them to another folder you have selected, or moves them to the Trash. The app operates within the macOS sandbox and has no access to other areas of your system.

## On Windows

The sections above describe the Mac. On Windows, sVectorLift stores the following exclusively on your PC, in the app's data folder (`%LOCALAPPDATA%\Packages\SwiftAppsBavaria.sVectorLift_hf9cyk3yb1b54\LocalState`):

- **Settings** in a file named `config.json`: the source folders, the recently used folders and the export options.
- **An app log** for troubleshooting (folder `Logs`, one file per day) and, after an unexpected error, **an error log** (`fehler.log`). Both are deleted automatically after seven days and never leave your PC.
- **The cache of the help window** (Microsoft Edge WebView2, folder `EBWebView`). It contains no personal data.

Windows does not back up this data to OneDrive. All of it is removed when you uninstall the app.

On Windows, too, sVectorLift only reads the folders you select and only writes to the destination folder you choose. At your request, it renames, moves or copies files, or moves them to the Recycle Bin. It makes no network connections, has no accounts and collects no data.

## Microsoft Store

On Windows, purchase, download and updates are handled by the Microsoft Store; Microsoft's privacy statement applies to them.

## Third-Party Services

sVectorLift does not use any third-party services, SDKs, or frameworks that collect data.

## Children

Since sVectorLift does not collect any data, there are no specific risks for children.

## Changes

Changes to this privacy policy will be published in this file. Since no data is collected, significant changes are not expected.
