# sVectorLift — Assistenza

sVectorLift è un'app per macOS dedicata alle vecchie raccolte di clipart. Ricostruisce come vero SVG i disegni dell'era CorelDRAW — documenti CorelDRAW (.cdr), Corel Binary Meta File (.cmx), Windows Metafile (.wmf) e Computer Graphics Metafile (.cgm) — e rende come immagine i QuickDraw 3D Metafile (.3dm, .3dmf). La tua raccolta appare in una finestra sfogliabile con albero delle cartelle, e puoi esportare un singolo file o un'intera selezione in un solo passaggio. I file che contengono soltanto un'immagine raster vengono esportati come PNG. sVectorLift non è un programma di impaginazione.

## Aiuto nell'app

sVectorLift ha un aiuto completo integrato. Lo apri dal menu oppure con ⌘/ (Comando–Barra).

Spiega come scegliere la cartella di origine e quella di destinazione, come visualizzare e selezionare le clipart, come esportare, quali abbreviazioni da tastiera esistono e come cambiare la lingua dell'app.

## Domande frequenti

**Al posto dell'anteprima compare un punto interrogativo.**
Il file non è stato letto: o è danneggiato, o è in un formato che sVectorLift non conosce.

**Il mio file ha estensione .cdr, ma gli altri programmi non lo aprono.**
Molti file con estensione .cdr sono in realtà file CMX. sVectorLift legge entrambi.

**Come cambio la lingua dell'app?**
macOS permette di impostare la lingua per singola app: Impostazioni di Sistema → Generali → Lingua e regione → sezione «App». Aggiungi lì sVectorLift e scegli la lingua che preferisci.
