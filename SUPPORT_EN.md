# sVectorLift — Support

sVectorLift is a macOS app for old clipart libraries. It rebuilds drawings from the CorelDRAW era — CorelDRAW documents (.cdr), Corel Binary Meta File (.cmx), Windows Metafile (.wmf) and Computer Graphics Metafile (.cgm) — as true SVG, and renders QuickDraw 3D Metafiles (.3dm, .3dmf) as an image. Your collection is shown in a browsable window with a folder tree, and you can export a single file or a whole selection in one step. Files that contain nothing but a raster image are exported as PNG instead. sVectorLift is not a page-layout tool.

## Help in the app

sVectorLift comes with a complete built-in help. Open it from the menu or press ⌘/ (Command–Slash).

It explains how to choose your source and destination folders, how to view and select clipart, how to export, which keyboard shortcuts exist, and how to change the app's language.

## Frequently asked questions

**A question mark appears instead of a preview.**
The file could not be read — it is either damaged or in a format sVectorLift does not know.

**My file has a .cdr extension but other tools cannot open it.**
Many files with a .cdr extension are in fact CMX files. sVectorLift reads both.

**How do I change the language of the app?**
macOS lets you set the language per app: System Settings → General → Language & Region → section "Applications". Add sVectorLift there and pick the language you want.
